## 9929 是什么，为什么带它的香港机器更贵

AS9929 是联通 CUII 精品网，定位对标电信 CN2 GIA。它和普通联通 169 骨干（AS4837）的差别不在技术参数表上：9929 面向企业客户、有 SLA、承载用户少，晚高峰几乎不拥塞；4837 是公共骨干，拥堵是常态。

这个差别直接换算成钱。香港机房本身的带宽成本就高于日本和新加坡，再叠加 9929 这种小带宽、高单价的线路资源，同配置的香港 9929 机器通常比日本 9929 贵一截，起步带宽也偏低。香港到华南直连可以做到 30ms 以内，华东实测通常在 40–60ms；日本到华东一般 50–80ms，但带宽资源更充裕，同样价格能买到更高配置。

所以你付的溢价买的是两样东西：物理距离带来的低延迟，和回程绕开公共骨干的稳定性。弄清楚这台机器到底给的是哪种“9929”，比看 CPU 型号重要。
